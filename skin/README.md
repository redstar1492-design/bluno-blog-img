# [GPT 작업] 네이버 블로그 bluno-economy 꾸미기 (2026-11-20, 대표 지시 · 모바일 제외)

대상: https://blog.naver.com/bluno-economy ("블루노의 경제 이야기", 대표 계정, 로그인은 대표가 함)
요청: 대표가 "카테고리 나누고, 이쁘게 꾸미고, 인기 블로그처럼 포맷까지 정리해 GPT가 그대로 작업"하라고 지시함.
Claude는 네이버 블로그를 열 수 없어서(안전 제한) 준비물만 만들었다. 실제 설정은 GPT가 대표 PC 크롬에서 한다.

## 0. 하지 말 것
- 기존 글 5편을 삭제하거나 공개 범위를 바꾸지 않는다.
- 비밀번호 입력, 결제, 블로그 마켓 가입, 유료 스킨 구매를 하지 않는다. 로그인이 풀리면 대표에게 넘긴다.
- 소개·타이틀·글 어디에도 "AI 진행자", "AI 목소리" 같은 말을 쓰지 않는다(대표 규칙 11/7).
- 맛집 글은 대표가 직접 다녀온 곳만 쓴다. 가 보지 않은 곳의 후기는 만들지 않는다.
- 이 지시서에 없는 일은 하지 않고 Issue에 질문으로 남긴다.

## 1. 카테고리 (4개, 하위 없이 단순하게, 대표 확정 "너무 많아요 → 간단하게")
경로: 관리 → 메뉴·글·동영상 관리 → 카테고리 관리 (블로그 홈 카테고리 칸의 `EDIT`을 눌러도 바로 열림)

| 순서 | 카테고리명 | 하는 일 |
|---|---|---|
| 1 | 블루노 경제 | 기존 "게시판"(5편)의 이름만 바꾼다. 유튜브 영상과 짝을 맞춘 경제 글(연금·세금·대출·금리) |
| 2 | 부동산 | 새로 추가 |
| 3 | 맛집·먹거리 | 새로 추가 |
| 4 | 생활 혜택 | 새로 추가 |

방법: "게시판" 선택 → 카테고리명을 `블루노 경제`로 수정. "카테고리 전체보기"를 누른 뒤 `+ 카테고리 추가`를 눌러야 하위가 아닌 같은 단계로 생긴다. 나머지 3개도 같은 방식이다. 공개 설정은 모두 공개, 글보기는 블로그형, 목록 열기는 "목록열기 5줄"로 둔다. 맨 아래 **확인**을 눌러 저장한다.
저장 뒤 카테고리마다 주소(`categoryNo=숫자`)를 적어 둔다. 4절 위젯 링크에 쓴다.

## 2. 상단 메뉴
경로: 관리 → 메뉴·글·동영상 관리 → 메뉴 관리 → 상단 메뉴 설정
- 블로그 메뉴는 "블로그"와 "안부"만 남기고 지도·서재·태그·프롤로그는 끈다.
- 카테고리 메뉴로 위 4개를 상단에 올린다. 순서는 블루노 경제 → 부동산 → 맛집·먹거리 → 생활 혜택.
(조사한 18곳 모두 카테고리 3~5개를 상단 메뉴로 올렸고, 안 쓰는 지도·서재는 뺀 곳이 많다.)

## 3. 프로필
경로: 관리 → 기본 설정 → 블로그 정보
- 블로그명: `블루노의 경제 이야기` (그대로)
- 별명: `블루노` (그대로)
- 소개글(현재 끝의 "(AI 진행자)"를 지우고 아래로 바꾼다):
  > 숫자로 보는 5분 경제, 블루노입니다. 연금·세금·대출·부동산 뉴스 속 숫자를 내 돈으로 바꿔 알려 드려요. 생활 혜택과 직접 가 본 맛집 이야기도 올립니다. 유튜브 "블루노의 경제 이야기"에서 영상으로도 보실 수 있어요.
- 블로그 프로필 이미지: 지금 이미지(블루노 캐릭터) 그대로 둔다.
- 블로그 주제: `비즈니스·경제` (이미 다른 값이면 이것으로)

## 4. PC 꾸미기 (스킨·타이틀·위젯)
경로: 관리 → 꾸미기 설정 → 레이아웃·위젯 설정 / 세부 디자인 설정(리모콘)

### 4-1. 레이아웃
- 2단, 본문 왼쪽 + 사이드바 오른쪽(사이드 폭 170 기본). 이미 2단이면 그대로 둔다.
- 사이드 위젯 순서: 프로필 → **직접등록 위젯(아래 4-3)** → 카테고리 → 검색 → 방문자. 달력·지도·이웃 커넥트·글 보내기 통계는 끈다.

### 4-2. 스킨·타이틀
- 스킨 배경은 단색 흰색 또는 연한 회색(#F4F3FB 근처) 기본 스킨을 고른다. 무료 기본 스킨만 쓴다.
- 리모콘 → 타이틀 → 디자인 → 직접등록 → 아래 이미지를 올린다. 영역 높이는 **300px**로 맞춘다.
  - 타이틀 이미지(966×300): https://redstar1492-design.github.io/bluno-blog-img/skin/title.png
  - 이미지에 블로그 이름이 들어 있으므로 타이틀 "블로그 제목" 글자는 **숨김**으로 한다.
- 지금 걸려 있는 385px 머리 이미지는 이 이미지로 바꾼다. 화면에서 위아래가 잘리면 높이를 300으로 다시 맞춘다.

### 6-1. 블루노 경제 (유튜브 영상 1편 = 글 1편)
- 제목: 숫자형 또는 검색형. 예) `가계빚 2,030조원, 내 대출은 괜찮을까? 금리별 월 상환액 표로 3분 점검` / `2026년 12월 국민연금 수령일 총정리`
- 순서: 머리띠 → 첫 문단 2~3문장(결론이나 숫자 먼저) → 유튜브 링크 한 줄과 영상 → 번호 소제목 3~4개(01. 02. 03.) → 표 1개 → "오늘 할 일" 체크리스트 → 출처(정부·기관 원문, 기준일) → 글 끝 배너 → 태그
- 이미지 6장 이상, 글자 2,000~4,000자, 해요체.
- 숫자는 Claude가 만든 영상 대본·설명란(검증 통과본)에서만 가져온다. 새 숫자를 지어내지 않는다.
- 참고한 블로그: 숫자로 보는 이슈(01goodday, 번호 소제목 3개 + 직접 계산), 한녕 경제로그(isshoko), 와이민(yminsong)

### 6-2. 부동산
- 제목: 검색형에 괄호 키워드. 예) `2026년 12월 청약 일정 총정리 (서울·경기 분양)`
- 순서: 머리띠 → 결론 한 문단 → 표(단지·일정·가격·조건) → 소제목 3개 → 내 상황별 체크 → 출처(청약홈·국토부, 기준일) → 끝 배너 → 태그 8~15개
- 참고한 블로그: 빠숑(ppassong), 제네시스박(genesis421, 유튜브와 같이 운영), 쇼킹부동산(jdliksa12)

### 6-3. 맛집·먹거리 (대표가 직접 다녀온 곳만, 사진·가격은 대표가 줌)
- 제목: `[동네·역 맛집] 가게명 - 한 줄 특징` 예) `[오산 맛집] ○○국밥 - 아침 7시에 문 여는 50년 노포`
- 순서: 머리띠 → 맨 위 정보(주소·전화·영업시간·휴무·주차, 사진이 아니라 글로) → 외관 → 메뉴판과 가격 → 음식 사진 사이에 짧은 소감 → 총평 한 문단(좋았던 점·아쉬운 점) → 네이버 지도(장소) 첨부 → 끝 배너 → 태그 6~10개
- 사진 10장 이상, 내 돈으로 먹었으면 "내돈내산"을 적는다. 4060이 좋아하는 국밥·냉면·한식·노포를 우선한다.
- 참고한 블로그: 문썬의 밥상(sielle83, 아저씨 입맛 노포), 안월(hellomonday_, 메뉴별 정리), 부산댁(hjdo2000)

### 6-4. 생활 혜택
- 제목: 숫자나 마감일을 넣는다. 예) `안 쓴 카드 포인트 현금으로 받는 법 (1포인트=1원, 3분이면 끝)`
- 순서: 머리띠 → 맨 위 요약 3줄(누가·얼마·언제까지) → 질문형 소제목(누가 받나요? 얼마예요? 어떻게 신청하나요?) → 신청 단계 번호 목록과 화면 캡처 → Q&A 2~3개 → "기준일·출처" 한 줄 → 끝 배너 → 태그
- 금액·조건은 정부·기관 원문과 대조한다(언론 한 곳만 보고 쓰지 않음).
- 참고한 블로그: 지식창고24시(happy_man0602, "오늘의 혜택" 구성), 정부지원금코리아(her550, 시니어 혜택 칸)

## 7. 운영 기준
- 발행: 주 3~4편부터. 매일 저녁 6시 유튜브 세트가 나오면 블루노 경제 글 1편이 기본이다. 하루 5편 이상 몰아 쓰지 않는다.
- 태그: 6~15개, 마지막에 `블루노의경제이야기`.
- 모든 글 끝에 이웃 추가 부탁 한 줄과 끝 배너.
- 기존 5편은 카테고리 "블루노 경제"에 그대로 둔다.
