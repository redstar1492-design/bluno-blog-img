# [GPT 작업] 네이버 블로그 bluno-economy 꾸미기 v3 (2026-11-20, 대표 확정 "A·A")

대상: https://blog.naver.com/bluno-economy (대표 계정, 로그인은 대표가 함)
바꾸는 이유(대표 지적 11/20):
- 이 블로그는 "블루노의 경제 이야기"가 아니라 **"블루노"라는 한 사람의 블로그**입니다. 경제는 그중 하나이고, 부동산·맛집·생활 혜택도 좋아하는 사람으로 보여야 합니다.
- 블루노 얼굴은 **프로필 사진 하나만** 씁니다. 타이틀·글 머리띠·글 끝 배너에는 얼굴을 넣지 않았습니다.
- 소개글은 만화책처럼 쉽게 씁니다.

Claude는 네이버 블로그 화면을 열 수 없습니다(안전 제한). 그래서 Claude가 준비물을 만들고, 실제 설정은 GPT가 대표 PC 크롬에서 합니다.

## 0. 하지 말 것
- 기존 글을 지우거나 공개 범위를 바꾸지 않습니다.
- 비밀번호를 입력하거나 결제·유료 스킨 구매를 하지 않습니다. 로그인이 풀리면 대표에게 넘깁니다.
- "AI 진행자", "AI 목소리" 같은 말을 쓰지 않습니다.
- 모바일 화면은 확인하지 않습니다(대표 확정 11/20).
- 이 지시서에 없는 일은 하지 않고 Issue에 질문으로 남깁니다.

## 1. 블로그 정보
경로: 관리 → 기본 설정 → 블로그 정보
- 블로그명: `블루노의 경제 이야기` → **`블루노`**
- 별명: `블루노` (그대로 둡니다)
- 소개글을 아래 문장으로 바꿉니다(그대로 복사).
  > 안녕하세요, 블루노예요! 연금·집값 뉴스 보다가 배고프면 맛집 찾아가요. 어려운 건 쉽게 풀어서 올릴게요 😊
  - 이모지가 저장되지 않으면 😊만 빼고 저장합니다.
- 프로필 이미지: 지금 쓰는 블루노 그림을 그대로 둡니다. 블루노 얼굴은 여기 하나만 씁니다.

## 2. 카테고리 이름 하나 바꾸기
경로: 관리 → 메뉴·글·동영상 관리 → 카테고리 관리
- `블루노 경제` → **`경제`**. 블로그 이름이 블루노라서 겹치기 때문입니다.
- 나머지 `부동산`, `맛집·먹거리`, `생활 혜택`은 그대로 둡니다. 순서도 그대로입니다.
- 이름만 바꾸면 categoryNo가 그대로라서 위젯 링크는 손대지 않아도 됩니다. 맨 아래 **확인**을 눌러 저장합니다.

## 3. 타이틀 이미지 바꾸기
경로: 관리 → 꾸미기 설정 → 세부 디자인 설정(리모콘) → 타이틀 → 디자인 → 직접등록
- 지금 이미지(skin/title.png)를 아래 이미지로 바꿉니다. 영역 높이는 **300px**입니다.
  - https://redstar1492-design.github.io/bluno-blog-img/skin3/title-a.png (966×300)
- 이미지에 "블루노"가 크게 들어 있으니, 타이틀 "블로그 제목" 글자는 계속 **숨김**으로 둡니다.
- 적용 버튼을 누릅니다.

## 4. 사이드 위젯 이미지 바꾸기
경로: 관리 → 꾸미기 설정 → 레이아웃·위젯 설정 → 직접등록 위젯 `블루노 바로가기` → 수정
- 위젯 HTML에서 카테고리 버튼 이미지 4개의 주소만 바꿉니다. `skin/widget-cat-`를 `skin3/widget-cat-`로 바꾸면 됩니다(4곳).
- `alt="블루노 경제"`는 `alt="경제"`로 바꿉니다.
- 유튜브 위젯(skin/widget-youtube.png)과 계산기 위젯(skin/widget-calc.png)은 그대로 둡니다.
- 링크 주소(categoryNo)는 바꾸지 않습니다.

## 5. 글에 쓰는 이미지 (참고, GPT가 할 일은 없음)
- 앞으로 글 맨 위 머리띠는 skin3/head-econ·head-home·head-food·head-life.png, 글 끝 배너는 skin3/post-footer.png를 씁니다. 글은 블로쟁이(Claude)가 준비합니다.
- 이미 올라간 글 5편의 이미지는 바꾸지 않습니다.
